# Volodymyr (@Sage-Cat)

I build practical C++/Qt applications and tools for reproducible Wi-Fi sensing
experiments. My public repositories include active utilities and datasets as
well as smaller educational projects; each project documents its own maturity
and limitations.

## Selected work

### Wi-Fi sensing and experiment tooling

- [csi_capturing_example](https://github.com/Sage-Cat/csi_capturing_example) —
  ESP32-S3 CSI/RSSI capture, experiment metadata, and offline analysis.
- [environment-interference](https://github.com/Sage-Cat/environment-interference) —
  repeatable Linux Wi-Fi interference surveys and experiment-readiness reports.
- [cwslab-public-experiments-data](https://github.com/Sage-Cat/cwslab-public-experiments-data) —
  sanitized datasets and reproducible public capture profiles.

### C++ and Qt applications

- [SageStore](https://github.com/Sage-Cat/SageStore) — a Qt desktop ERP MVP
  with an HTTP server and SQLite persistence.
- [AutoCenterDesktop](https://github.com/Sage-Cat/AutoCenterDesktop) — a legacy
  Qt inventory, sales-document, and barcode-label application.

For questions or feedback, please use the issue tracker in the relevant
repository so the discussion stays with the project.
